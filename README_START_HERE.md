# MINJEONG KIM Portfolio - Starter Home

This is the first-pass GitHub Pages version of the Notion portfolio home page.

## Copy into your repository

Copy these folders/files into your local `minjonyfilm.github.io` repository:

- `index.html`
- `css/`
- `js/`
- `images/`
- `projects/`

Then run:

```bash
git add .
git commit -m "Build Notion-style portfolio home"
git push
```

After GitHub Pages deploys, visit:

https://minjonyfilm.github.io/
